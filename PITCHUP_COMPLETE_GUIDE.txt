 1. فكرة المشروع
───────────────────────────────────────────────

PitchUp هي منصة حجز ملاعب رياضية (فوتبول/باسكت/تنس) بتشتغل زي اوبر بالظبط:
  - صاحب المنصة (الـ Super Admin) هو المالك الوحيد للنظام
  - اصحاب الملاعب (Pitch Owners) بيسجلوا ملاعبهم على التطبيق
  - اللاعبون (Players) بيحجزوا الملاعب
  - المنصة بتاخد عمولة 10% من كل حجز

ملاحظة المستخدم: المستخدم مش عايز اي مميزات AI تظهر للمستخدمين النهائيين.
                   مش عايز اعدادات سيرفر او خيارات تقنية تظهر للاعبين او اصحاب الملاعب.

 5. قاعدة البيانات (Prisma Schema)
───────────────────────────────────────────────

الموديلز الموجودة في backend/prisma/schema.prisma:

  User { id, name, phone (unique), role (PLAYER|OWNER), createdAt }
  Pitch { id, name, description, location, pricePerHour, images (JSON string),
          amenities (JSON string), sport (FOOTBALL|BASKETBALL|TENNIS), ownerId, createdAt }
  Booking { id, userId, pitchId, date (YYYY-MM-DD), startTime (HH:mm),
             endTime (HH:mm), status (CONFIRMED|CANCELLED), price, createdAt }
  MatchRequest { id, userId, sport, location, date, time, playersNeeded, message, createdAt }

ملاحظة مهمة: SQLite مش بيدعم enums او arrays، عشان كده:
  - الـ role, status, sport كلها String مش enum
  - images و amenities مخزنة كـ JSON string وبتتـ parse بـ safeParse() في index.ts

 6. الـ API Endpoints الكاملة
───────────────────────────────────────────────

Base URL (محلي): http://localhost:3001/api
Base URL (Cloud): [لازم يتحدد بعد الـ deployment - شوف القسم 9]

--- Health ---
GET  /api/health

--- Pitches ---
GET  /api/pitches
GET  /api/pitches/:id
POST /api/pitches  Body: { name, description, location, pricePerHour, sport, ownerId, images?, amenities? }

--- Bookings ---
POST  /api/bookings  Body: { userId, pitchId, date, startTime, endTime, price }
GET   /api/bookings/:userId
PATCH /api/bookings/:id/cancel

--- Match Requests ---
GET  /api/match-requests
POST /api/match-requests  Body: { userId, sport, location, date, time, playersNeeded, message }

--- Users / Auth ---
POST /api/users/register  Body: { name, phone, role }
POST /api/users/login     Body: { phone }
GET  /api/users

--- Admin ---
GET    /api/admin/stats
GET    /api/admin/bookings
DELETE /api/admin/pitches/:id
DELETE /api/admin/users/:id

 9. خطوات الـ Deployment الكاملة (الاولوية القصوى)
───────────────────────────────────────────────

المشكلة الحالية:
  الداشبورد على Vercel بيظهر 404 لان الـ backend على localhost مش Cloud
  كمان SQLite بيتمسح على Cloud عند كل restart

STEP 1: انشاء PostgreSQL على Neon.tech (مجاني - مش محتاج كارد)
  1. روح لـ https://neon.tech
  2. Sign up بـ GitHub
  3. New Project → اسمه "pitchup"
  4. خد الـ Connection String:
     postgresql://neondb_owner:xxxxxx@ep-xxx.us-east-2.aws.neon.tech/neondb?sslmode=require

STEP 2: تحديث الـ Backend لـ PostgreSQL
  افتح: backend/prisma/schema.prisma
  غير:  provider = "sqlite"
  لـ:   provider = "postgresql"

  في backend/.env:
  غير:  DATABASE_URL="file:./dev.db"
  لـ:   DATABASE_URL="[Neon Connection String]"

  رن في terminal:
    cd "c:\Users\MoBadawy\Desktop\New folder\backend"
    npx prisma migrate deploy
    npm run seed

STEP 3: نشر الـ Backend على Railway.app (مجاني - مش محتاج كارد)
  1. روح لـ https://railway.app
  2. Sign in بـ GitHub
  3. New Project → Deploy from GitHub repo → mohammedelshokry/-New-Repository
  4. Root Directory: backend
  5. Variables:
     - DATABASE_URL = [Neon Connection String]
     - PORT = 3001
     - NODE_ENV = production
  6. Railway هيديك URL: https://new-repository-production.up.railway.app

STEP 4: تحديث الـ API URLs
  mobile-app/lib/providers/api_provider.dart:
    const String kProductionApiUrl = 'https://[RAILWAY-URL]/api';

  web-dashboard/src/lib/api.ts:
    baseURL: 'https://[RAILWAY-URL]/api'

STEP 5: Push لـ GitHub
  cd "c:\Users\MoBadawy\Desktop\New folder"
  git add .
  git commit -m "Update API URLs to production Railway backend + PostgreSQL migration"
  git push origin main

  بعد الـ push:
  - Vercel هيعمل redeploy تلقائي للداشبورد
  - GitHub Actions هيبني الـ APK تلقائي

STEP 6: تحميل الـ APK
  1. روح لـ https://github.com/mohammedelshokry/-New-Repository/actions
  2. افتح "Build Android APK" workflow
  3. في Artifacts حمل "PitchUp-Release-APK"
  4. ابعت app-release.apk على WhatsApp
